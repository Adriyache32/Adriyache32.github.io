# Adriyache32.github.io

Landing page del servidor de Minecraft **Nervalia** (antes *Donde Felipe* server).

## Tech Stack
- HTML5 / CSS3 / Vanilla JS
- GitHub Pages + Actions deploy
- Responsive, sin build step

## Deploy
Automático en push a `main` via `.github/workflows/deploy.yml`.

## Estructura
- `index.html` - Landing principal
- `assets/` - Imágenes, favicon
- `styles.css` - Estilos
- `script.js` - Interactividad ligera

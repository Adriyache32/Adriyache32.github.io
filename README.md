Landing page oficial del servidor de Minecraft **Nervalia** (chanchos MC studios): información del servidor, enlaces y ranking de jugadores.

## 📦 Contenido

| Archivo | Qué es |
|---|---|
| `index.html` | Página principal (info del servidor) |
| `legal.html` | Términos y avisos |
| `data.json` | Datos del servidor (se edita para actualizar la web) |
| `ranking-patoviciado-v1.2.html` | Ranking de jugadores |
| `404.html` | Página de error |
| `fonts/`, `logos/`, `favicon.svg`, `og-ranking.jpg` | Recursos |

## 🚀 Ver el sitio

Publicado con **GitHub Pages** → https://adriyache32.github.io/

Para probarlo local:

```bash
python3 -m http.server 8000
# abre http://localhost:8000
```

## ✏️ Actualizar datos

Edita `data.json` y haz commit; la web lo lee automáticamente.
